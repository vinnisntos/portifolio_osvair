# Osvair dos Santos — Transporte Executivo

Landing page de apresentação para um serviço de transporte executivo e particular: transfers para aeroportos, viagens corporativas, eventos e trajetos intermunicipais.

O site é uma página única (single page), com visual inspirado em estrada/asfalto noturno, focada em apresentar o profissional, o veículo e os canais de contato para agendamento.

🔗 [osvairsantos.com.br](https://osvairsantos.com.br)

## Stack

- **HTML5** — página estática única
- **[Tailwind CSS](https://tailwindcss.com/)** (via CDN) — estilização utilitária, com tema customizado (cores, tipografia e espaçamentos próprios)
- **[Lucide Icons](https://lucide.dev/)** (via CDN) — ícones
- **JavaScript vanilla** — animações de revelação ao rolar a página (Intersection Observer) e inicialização dos ícones

Sem build step, bundler ou dependências instaladas: é um projeto 100% estático, pronto para deploy direto (ex.: GitHub Pages, com domínio customizado via `CNAME`).
